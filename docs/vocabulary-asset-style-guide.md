# 儿童英语词汇素材视觉规范 V1.0

> 目标：统一生成与人工制作的词汇图片，使词库学习馆、主题世界卡片和后续活动保持同一种高质量儿童教育视觉语言。

## 1. 目标风格

以项目确认的参考样式为准：**高质量儿童启蒙 3D 玩具 / 黏土 / 软陶风**。

核心特征：
- 单个主体居中，儿童一眼可识别；
- Q 版、圆润、可爱，但不能过度变形到难以识别；
- 材质像精致玩具、软陶或磨砂塑料，避免真实照片质感；
- 柔和棚拍光，允许轻微高光与落地阴影；
- 背景使用浅色纯色或柔和渐变，不堆叠复杂场景；
- 色彩明快但柔和，整体达到成熟儿童教育产品的精致度。

## 2. 构图标准

- 输出比例：**1:1**；
- 推荐源尺寸：**1024×1024**，入库时优先压缩为 WebP；
- 主体完整，不裁掉关键结构；
- 主体占画面约 **60%–80%**；
- 四周保留自然留白；
- 视角优先正面或 3/4 正面；
- 不在素材图内部添加英文、中文、边框、Logo 或水印；
- 一个词原则上只出现一个主要对象；需要表达集合、数量、动作、方位时按专门模板处理。

## 3. 分类规则

### 3.1 具体名词
如 apple / elephant / bus / chair。

采用单体 3D 玩具卡片图，是优先级最高的素材类型。

### 3.2 动物
使用幼态、友好、圆润比例，可适当放大头部与眼睛，但保留物种关键特征。

### 3.3 交通工具
采用精致玩具模型感，轮廓清晰，避免道路、城市等复杂背景抢焦点。

### 3.4 家居 / 学习用品
单体展示，保持真实物体关键结构，同时统一玩具材质和圆润边缘。

### 3.5 颜色 / 数字 / 形状
优先程序化生成或复用模板，不为每个概念重复生成一张独立图片。

### 3.6 动作 / 方位 / 比较概念
使用统一角色或同一物体的可控组合图，不用随机风格的独立插画。

## 4. 文件规范

项目运行时优先按英文词读取：

```text
frontend/public/vocabulary-assets/apple.webp
frontend/public/vocabulary-assets/elephant.webp
frontend/public/vocabulary-assets/bus.webp
```

候选格式顺序：
1. `.webp`
2. `.png`
3. `.jpg`
4. 旧版语义 SVG
5. 程序化占位

文件名规则：
- 全部小写；
- 空格和撇号转为 `-`；
- 仅保留 `a-z 0-9 -`；
- 例如 `We'll` → `we-ll.webp`。

正式新增素材优先使用 WebP。推荐单图控制在约 50–200 KB；确需高分辨率时再单独评估。

## 5. 通用生成提示词

```text
为儿童英语启蒙应用生成一张高质量词汇卡片素材，主题是“{word}”。

视觉风格：精致的儿童 3D 玩具 / 黏土 / 软陶风格，Q版但清晰易识别，
造型圆润、柔和、可爱，达到成熟儿童教育产品的视觉质量。

构图：仅一个主要主体，居中展示，主体完整，占画面约 60%–80%，
四周有适度留白，优先使用正面或 3/4 正面视角。

材质与光影：柔和的磨砂玩具或软陶材质，柔和明亮的棚拍光，
允许轻微高光和自然落地阴影，不要强烈明暗对比。

背景：干净的浅色纯色或柔和渐变背景，背景不能出现复杂场景或干扰物。

限制：不要文字、不要水印、不要Logo、不要边框、不要多个主要主体、
不要写实摄影、不要恐怖或成人风格、不要复杂装饰。

输出：1:1 正方形，1024×1024。
```

## 6. 负面约束

统一排除：
- photorealistic / documentary photo；
- busy background / clutter；
- multiple competing subjects；
- text / watermark / logo；
- dark horror / aggressive styling；
- metallic sci-fi styling；
- blurry / low detail；
- cropped key body parts；
- 过度拟人导致词义识别困难。

## 7. 验收标准

每张图片入库前至少确认：
1. 不看文字时，成年人和儿童能否快速判断主体是什么；
2. 与已有 apple / elephant / bus 目标风格是否一致；
3. 是否只有一个明确视觉焦点；
4. 背景是否足够干净；
5. 是否存在文字、水印、Logo；
6. 缩小到 200px 后仍能清晰识别；
7. 是否适合在 1:1 卡片中直接使用。

不满足以上任一核心条件的素材不得作为正式词汇图发布。
