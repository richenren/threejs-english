# 儿童基础英语 2000 词库

- 文件：`kids-core-2000.csv`
- 条目数：2000
- 目标：作为 5–8 岁启蒙产品的长期核心词库底座；这是项目课程词表，不是任何商业出版物的原样复制。
- 生成方法：从 ECDICT 的 Oxford/Collins 核心标记交集生成候选，按 ECDICT 当代词频 `frq` 排序，移除明显不适合低龄儿童的成人、毒品、赌博和重度暴力词，再取前 2000 个。
- 中文释义：基于 ECDICT 释义，使用 OpenCC 的繁转简映射并压缩为短释义；高频功能词使用项目规则校正。
- `category/worldTags`：给明显适合主题世界的词打标签，其余为 GENERAL。一个词可属于多个 World，例如 `apple` 可同时属于 KITCHEN 和 SUPERMARKET。
- `rank`：本项目内部排序号，仅用于课程编排，不宣称等同任何官方考试或商业词频排名。
- 数据来源：ECDICT / ECDICT-Traditional-Chinese（MIT）；繁简转换规则来自 OpenCC（Apache-2.0）。
- 注意：自动词典释义存在多义词“首义项不一定最适合儿童”的情况。内置安装功能会按用户明确选择直接批准；后续素材审核/教研阶段仍建议抽样修订释义。
